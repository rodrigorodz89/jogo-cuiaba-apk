# Jogo Cuiabá — APKs para teste

Downloads do jogo (Android) para instalar no tablet/celular.

**Baixar a versão mais nova:** [jogo-cuiaba.apk](https://github.com/rodrigorodz89/jogo-cuiaba-apk/releases/latest/download/jogo-cuiaba.apk)

O jogo confere este repositório ao abrir e avisa quando há uma versão nova (arquivo `versao.json`).

Versão pessoal, não publicada na Play Store. Créditos dos modelos 3D dentro do jogo (menu de configurações → "i").
